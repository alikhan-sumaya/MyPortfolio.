MY PORTFOLIO

Files:
- index.html: portfolio content
- style.css: page styling and responsive layout
- script.js: mobile navigation and current footer year

RUN LOCALLY:
1. Extract this ZIP.
2. Open the extracted MyPortfolio folder in Visual Studio Code.
3. Open index.html in a browser, or install the Live Server extension and
   right-click index.html > Open with Live Server.

BEFORE SHARING:
- Replace YOUR_EMAIL@example.com with your actual email.
- Update the LinkedIn URL.
- Update your graduation year.
- Replace the GitHub profile links in project cards with individual project URLs.
- Add your resume as resume.pdf in this folder.

PUBLISH:
Upload the files to a GitHub repository and enable GitHub Pages in
Settings > Pages > Deploy from a branch > main > /(root).
